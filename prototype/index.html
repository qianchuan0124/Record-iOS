已确认的方案

产品决策已经全部落进原型，下面是最终口径；底部中央「＋」已选定 B 悬浮圆形（无描边）。

01导航：4 Tab + 中央「＋」

账单 / 分析 / ＋ / 资产 / 设置。薪酬、存款、预算合并进「资产」，用分段控件切换；「＋」是全局唯一记账入口。

已落地：所有界面统一为 4 Tab；中央按钮已选定 B 悬浮圆形（无描边）。

02首版范围：全做

账单、分析（概览/年度/时间线）、薪酬与个税、存款与银行、预算、自定义分类、Excel 导入导出、CloudKit 同步全部进 1.0。

开发顺序：数据层 → 账单闭环 → 分析/年度 → 资产 → 设置/同步 → 导入导出。

03同步：SwiftData + CloudKit

设备间自动同步走 CloudKit 私有库；桌面端只通过 Excel 导入/导出 迁移，不读取数据库文件。

实现要点：首次启动把本地数据上传 CloudKit；导入 Excel 按 syncId 去重；冲突以「最后修改时间」为准。

04记账输入：自定义键盘

类型 → 金额 → 一级分类 → 二级分类 → 日期/备注 一屏完成；数字键盘常驻。

已落地：中央「＋」打开全屏记一笔，保存后回到原页面。

05自定义分类：放开 + 归档

可新增、重命名、排序、删除。删除默认「归档」：历史账单保留分类快照，汇总归入「已归档」；「未分类」只做系统兜底。

为什么：比一律显示未分类更可逆，也不改写往年报表。

06资产首页：分段控件

沿用当前方案：资产 Tab 顶部用 存款 / 薪酬 / 预算 三段切换，不做「总览 → 二级页」的额外层级。

已落地：两个资产首页共享同一套头部与分段控件。

07不引入账户 / 银行卡

删除年度页的「银行卡」筛选与交易排行里的账户信息；数据模型不加 `Account`、不加 `accountId`。

影响：年度页仅保留年份筛选；交易排行显示「名称 + 时间 + 金额」。

08不做「不计入」

不新增 `excludeFromStats`，所有账单都参与收入、支出与结余统计；保留桌面版已有的「计入预算」开关。

注意：转账、还款会按普通收支计入；如后续需要，再作为 1.1 的字段扩展。

09安全、适配与技术底座

不做应用锁；只支持竖屏；最低 iOS 18；SwiftUI + SwiftData + Swift Charts。

已落地：设置页无安全分组，原型全部 390×844 竖屏。
